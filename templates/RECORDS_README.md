# AI 작업 기록 레포

이 레포는 **ai-workflow** 가 자동으로 관리하는 작업 기록 저장소입니다. (계정 `{{login}}`)
AI(Claude Code)로 작업한 내용이 **카드(이슈)** 와 **작업 일지(md)** 로 여기에 쌓이고, 진행 상황은 GitHub Projects 보드에서 봅니다.

- 보드: [{{board_title}}]({{board_url}})
- 이 레포는 **비공개**로 두세요. 요청 원문, 수정 파일 목록, AI의 답변이 그대로 올라갑니다.
- 사람이 직접 고치지 않아도 됩니다. 아래 구조를 지키면 됩니다.

## 무엇이 어디에 쌓이나

| 위치 | 내용 | 만드는 주체 |
|---|---|---|
| **Issues** | 세션(요청 단위)마다 카드 하나. 본문에 요청·수정 파일·커밋, 코멘트에 작업 보고(✅)와 확인 요청(❓) | 훅이 자동 |
| **Projects 보드** | 카드가 컬럼으로 정리됨: Backlog → AI작업중 → 판단필요 → 검토대기 → 완료 | 훅이 자동 이동 |
| **`records/<프로젝트>/`** | 세션마다 일지 md 하나. **요청 원문 · 결정한 사항 · 반영된 사항 · 진행 과정(AI 답변·도구 호출 전체) · 결과 보고** 순서. 증적용이라 요청·답변을 자르지 않음 | 훅이 자동 |
| `README.md` (이 파일) | 설명서 | 설정 때 한 번 |

일지 파일 이름은 `날짜_시각초_세션ID앞8자리-임의값.md` 입니다. 세션마다 파일이 따로이고 이름에 임의값이 섞여 있어서, 같은 프로젝트의 다른 기능을 여러 세션·여러 PC에서 동시에 작업해도 서로 덮어쓰지 않습니다. 같은 이름이 이미 있고 다른 세션의 것이면 `-2`, `-3` 을 붙여 올립니다.
같은 내용의 로컬 사본은 각 PC의 `~/.ai-workflow/records/` 에도 남습니다.

## 작동 방식

```
claude-personal / claude-work 세션
        │  (Claude Code 훅이 요청·수정·커밋·질문·답변 끝을 감지)
        ▼
  로컬 대기열 ──▶ 전송기 1개 ──▶ GitHub (이 레포의 이슈 + records/ 일지 + 보드 카드)
```

1. **요청이 들어오면** 일지에 새 항목이 생기고, 작업이 길어지면 카드가 만들어져 **AI작업중** 이 됩니다.
2. **AI가 질문하면** 카드가 **판단필요** 로 가고 ❓ 코멘트가 붙습니다.
3. **답변이 끝나면** 카드가 **검토대기** 로 가고 마지막 답변이 ✅ 작업 보고로 붙습니다. 일지도 갱신됩니다.
4. **확인이 끝나면** 이슈를 닫습니다 → **완료** (개인 모드에서 커밋·푸시까지 하면 자동 완료).
5. 완료 후 14일이 지난 카드는 보드에서 자동 보관됩니다 (이슈는 그대로).

한 번의 짧은 질문처럼 기록이 필요 없는 요청은 카드가 만들어지지 않고, `ai-board off`(세션 전체)로 기록을 끌 수 있습니다.

## 카드 읽는 법
- 제목: `[프로젝트] 요청 요약 > 수정된 내용`
- 라벨: `ai-card`, `proj:<프로젝트>` (보드에서 `label:proj:<이름>` 필터로 프로젝트별 보기)
- 본문 맨 아래 **이어서 열기** 명령으로 그 세션을 다시 열 수 있습니다.
- 보드의 **검토필요도**(낮음/중간/높음) 칸은 AI가 보고 끝에 적은 값입니다. 높음부터 보세요.

## 자주 쓰는 명령

```bash
ai-board                      # 보드 열기
ai-board status               # 연결된 계정·레포·보드와 대기열 점검
ai-board off | on             # 세션 중 기록 끄기 / 켜기
```

## 지우거나 옮길 때
- 레포를 지우면 카드와 일지가 모두 사라집니다. 보관만 하려면 Archive 하세요.
- 레포나 보드 이름을 바꾸거나 다른 곳으로 옮기면 `python3 ~/ai-workflow/lib/boardsetup.py --repo <새 이름> --board <번호>` 로 다시 연결하세요.
