# lite 모드: 지정한 문서만 읽고 가볍게 작업

이번 세션은 `core.md`의 문서 규약(STATUS/worklog/ADR/plans)을 적용하지 않는다.

## 규칙
- 사용자가 지정한 문서(`-d` 로 전달되었거나 대화에서 지시한 문서)만 읽고, 그 문서의 지시대로 작업한다. 지정된 문서가 없으면 사용자의 요청만 따른다.
- 사용자가 요청하지 않은 한 STATUS.md, worklog, ADR, plans, GitHub 보드를 읽거나 갱신하지 않는다.
- 지정 문서가 갱신을 요구하면 그 문서가 요구하는 것만 한다.
- 탐색 범위를 넓히지 않는다. 요청과 직접 관련된 파일만 본다.
- 보고는 결과 위주로 짧게 한다.

## 유지되는 안전 규칙
- 커밋·push는 사용자에게 먼저 묻는다.
- 시크릿(`.env`, 키, 토큰)은 커밋하지 않고 출력·문서에도 적지 않는다.
- 되돌리기 어려운 작업(데이터 삭제, 배포, force push)은 실행 전에 확인한다.
